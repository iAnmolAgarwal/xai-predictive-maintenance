# Why Did the Model Flag This Machine?

Explainable-AI IoT predictive maintenance: a standard predictive-maintenance
pipeline (MQTT replay → feature engine → gradient-boosted model) with SHAP
explanations for every alert, rendered in a dashboard that ranks the
contributing sensor features by importance.

Built for the IoT Analytics lab at JIIT Noida. Includes a Node-RED flow for
lab-format compliance.
